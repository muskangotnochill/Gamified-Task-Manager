# 🎮 Gamified Task Manager

A React-based productivity application that converts daily tasks into a reward-based leveling system.

---

## 📌 Project Overview

The Gamified Task Manager is designed to motivate users by rewarding task completion with XP (Experience Points). As users complete tasks, they gain XP and level up.

This project demonstrates core ReactJS concepts including:
- State Management
- Props
- React Hooks (useState, useEffect)
- Component Reusability
- LocalStorage Integration
- JavaScript Array Methods

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Earn 10 XP per completed task
- Automatic Level system (Every 100 XP = Level Up)
- Dynamic progress bar
- Delete tasks
- Data persistence using LocalStorage
- Responsive modern UI

---

## 🛠 Tech Stack

- ReactJS (Functional Components)
- JavaScript (ES6)
